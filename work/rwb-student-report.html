01

Overview

A digital behavior-score management system built for Ratwinit Bangkaeo School, created to help teachers manage student behavior records and score deductions in a more organized and efficient way.

It replaces traditional paper tracking with a web platform backed by the Google Sheets API, so records stay accessible and up to date for both teachers and administrators.

02

Features

  • Student information management
  • Behavior score deduction system
  • Score deduction history tracking
  • User login and authentication system
  • Admin and teacher management dashboard
  • Real-time data updates
